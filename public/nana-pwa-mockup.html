Parent brief

The shareable summary

One-page brief for the other parent / grandparents — exportable, no Nana branding when shared.

What this is — and isn't

  • This IS what a PWA of Nana would feel like on iPhone. Same code as the website, just installed to the home screen.
  • This IS NOT in the App Store. Parents install it directly from Safari → Share → Add to Home Screen.
  • Works offline-ish — last-viewed school reports cached. New chats need internet (Nana lives on the server).
  • Push notifications work on iOS 16.4+ — but only after the parent installs to home screen first.
  • Build effort — a manifest file, a service worker, some icons. Maybe a day of work end-to-end, no app-store review.
